# Security policy

## Reporting a vulnerability

Please do not open a public issue for an exploitable security vulnerability. Contact the repository maintainer privately through the contact method listed on the GitHub profile.

## Safe-use notes

VPCraft is an educational demo. It is not designed to store sensitive or regulated data. The default public HTTP endpoint is not suitable for production workloads. Before production use, add TLS, authentication, hardened administration, centralized secrets management, backups, patching, threat monitoring and a production-grade data tier.
